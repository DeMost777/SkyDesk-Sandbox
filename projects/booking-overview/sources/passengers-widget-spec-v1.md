## Спецификация (как прислана)

Название:
Виджет Passengers

Назначение
Passengers Widget — отображает полную информацию о каждом пассажире, связанном с бронированием. Он служит быстрым справочником для агентов, позволяя получить доступ к персональным данным пассажиров и быстро оценить полноту введённых данных.

Структура виджета
Карточка пассажира (одна запись)
Каждый пассажир представлен в отдельной карточке, содержащей:

1. Номер пассажира
   * Нумерация пассажиров по принципу GDS
2. Основная информация
   * Полное имя (Имя + Middle Name + Фамилия).
   * Аббревиатура титула (`Mr`, `Mrs`, `Ms`, `Dr` и др.) — без точки и скобок.
3. Индикаторы состояния данных

* Passenger type
   * ADT, CNN, INF

| Код | Значение | Описание |
| --- | --- | --- |
| **ADT** | Adult | Взрослый пассажир (старше 12 лет) |
| **CNN** | Child | Ребёнок (2–11 лет) |
| **INF** | Infant | Младенец (до 2 лет, без отдельного места) |
| **INS** | Infant with seat | Младенец с отдельным местом |
| **CHD** | Child | Альтернативный код ребёнка (аналог CNN, зависит от GDS/авиакомпании) |

* Date of Birth (DOB)
   * Отображается, если нет данных паспорта.
   * Если паспорт есть, индикатор даты рождения не отображается, тк указан уже в Passport.
* Passport
   * Если паспорт есть → зелёный индикатор check.
   * Если паспорта нет → серый индикатор x.
* Frequent Flyer
   * Индикатор отображается, если у пассажира есть хотя бы один Frequent Flyer.
   * Если отсутствует → индикатор скрыт.

Логика индикаторов позволяет агенту сразу понять, какие данные введены, а каких нет.

* Для перелётов внутри Европы достаточно даты рождения и пола.
* Для международных перелётов необходим паспорт.

4. Развернутая карточка (Show more)
При нажатии на кнопку Show more карточка раскрывается и показывает подробные блоки:
   * Personal information (отображается всегда, даже при отсутствии данных).
      * Date of Birth
      * Gender
      * Nationality
      * Passport/ID number
      * Country of issue
      * Date of expiration
      * Если поле пустое — отображаем прочерк (-).
   * Frequent Flyer
      * Секция появляется только если у пассажира есть хотя бы одна карта.
      * Содержит список номеров карт и соответствующих авиакомпаний.

Индикаторы в карточке (логика)

Индикатор Date of Birth:
- Отображается, если у пассажира нет паспортных данных.
- Если паспорт есть — индикатор дата рождения не показывается, тк по умолчанию есть в пасспорте.
Основная логика в том что, для перелетов внутри Европы достаточно даты рождения и пола.
Для международных перелётов необходим паспорт → поэтому важно видеть индикатор паспорта.

Индикатор Passport:
- Отображается иконкой "check", если у пассажира заполнены данные паспорта.
- Если паспорта нет — показываем иконку «X Passport» (как в примере с Camila Brown Miller).

Индикатор Frequent Flyer:
- Отображается только если есть хотя бы один Frequent Flyer.
- Если Frequent Flyer отсутствует — индикатор не отображаем.

Развернутая карточка (Show more)

При раскрытии карточки появляются секции:

1. Personal information — всегда отображается. Если данных нет, подставляем прочерк (-).
Состав: Дата рождения, Пол, Национальность, Паспорт/ID, Страна выдачи паспорта, Дата окончания.

2. Frequent flyer — отображается только если у пассажира есть данные.
Список карт лояльности с привязкой к авиакомпаниям.

Обработка отсутствующих данных
- Если в Personal information отсутствует информация (например, паспорт или страна), вместо значения отображается прочерк (-).
Если у пассажира нет Frequent Flyer — блок полностью скрывается.

- **Подсказка бейджа:** `Tooltip` (`Popover` `#fafaf9`, рамка `Border`, радиус 6, отступы 12×6, `Shadow Medium`, текст 14) над бейджем: «Passenger 1».
- **Аннотации разработчикам в узле карточки:** у ячейки Date of birth — «Если это infant или child дата рождения должна быть обязательно.»; у кода авиакомпании — «Frequent flyer относиться к определенной авикомпании. Поэтому отображаем код авиакомпании который был выдан.»

Сочетания индикаторов (узел `2294:505086`, подписи авторов):

| Данные | Индикаторы |
|---|---|
| Есть дата рождения, нет паспорта, есть FF | `✓ Date of Birth │ ✗ Passport │ ✓ Frequent flyer` |
| Есть паспорт, есть FF | `✓ Passport │ ✓ Frequent flyer` |
| Нет даты рождения, нет паспорта, нет FF | `✗ Date of Birth │ ✗ Passport` |

«Вопросы» автора (узел `1487:424885`, дословно по смыслу):

1. Тип пассажира хорошо бы видеть всегда, особенно infant и child: их нельзя выписать без даты рождения (иногда нужен только месяц, иногда полная дата). Пол и тип — не одно и то же: MR / MRS — это пол, Adult / Child / Infant — тип.
2. Нужно ли показывать FOID отдельно? Это идентификационный номер (паспорт, ID, права), некоторые авиакомпании требуют его. Если добавляем, нужен индикатор. Возможен сценарий «FOID есть, паспорта нет».
3. Как узнаём пол? Если пола нет, каким цветом отображать?
4. Нужно ли показывать блок FF в развёрнутой карточке, если FF нет? — спецификация выше отвечает: блок скрывается.
